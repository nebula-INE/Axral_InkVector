## ツール一覧

| キー | ツール | 操作 |
|------|--------|------|
| `P` | ペン | クリックでノード追加、ドラッグでベジェハンドル、ダブルクリックで確定 |
| `A` | Reshape | パス選択→ノード/CPをドラッグ。スムーズ連動あり |
| `V` | 選択 | クリック/ラバーバンドで複数選択。バウンディングボックスでスケール・回転 |
| `H` | 手のひら | パン（Alt+ドラッグでも可） |
| `E` | 消しゴム | パスをクリックで削除 |
| `Shift+A` | アンカー追加 | セグメント上にクリックでノード挿入 |
| `Shift+D` | アンカー削除 | ノードをクリックで削除 |
| `W` | 線幅編集 | パスを選択して横ドラッグで線幅変更 |
| `B` | バケツ塗り | 閉じた領域をクリックで塗り色を適用 |
| `C` | 交差点切断 | ノード付近クリックでパスを2分割 |

## 機能詳細

### ブラシスタジオ
- Gペン / 鉛筆 / マーカー / 水彩 / エアブラシ
- 筆圧対応ブラシは描画速度に応じた幅変化を再現
- 「ブラシスタジオ…」ボタンでブラシ選択ダイアログ

### シンメトリー定規（左ドック）
- なし / 左右 / 上下 / 4方向
- 中心座標を自由に設定
- ペンツールで描くと自動的に対称パスを生成

### レイヤーシステム（右ドック）
- 追加・削除・上下移動（ダブルクリックで名前変更）
- 可視/ロック切り替え
- 不透明度スライダー
- ブレンドモード：通常 / 乗算 / スクリーン / オーバーレイ / 明度

### プロパティパネル（右ドック）
- **スタイル**: ストロークカラー・太さ、塗りカラー、不透明度、パス開閉
- **情報**: ノード数・バウンディングボックスサイズ
- **変形**: X/Y/W/H 数値入力で正確な変形

### 複数選択・変形
- ラバーバンドで範囲選択
- Shiftクリックで追加選択
- バウンディングボックスの四隅ハンドルでスケール
- 上部ハンドルで回転
- 矢印キーで整列移動

### SVG
- 完全なSVG読み書き（M/C/L/Z対応）
- `data-*` 属性でレイヤー名・ブレンドモード・グループ情報を保持
- 他アプリのSVGも読み込み可能

## アーキテクチャ

```
Document
├── Layer[]  (visible/locked/opacity/blend)
│   └── items: VPath | VGroup
│       └── VGroup
│           └── VPath[]
│               └── VNode[] (pos + cp_in + cp_out + smooth)
└── symmetry (SYM_NONE/H/V/CROSS)

Canvas (QWidget)
├── Tool system (10種)
├── Undo/Redo (QUndoStack 200ステップ)
├── Rubber-band 複数選択
├── Bounding box 変形 (scale + rotate)
└── Symmetry engine

BrushEngine
└── apply_brush_stroke() — 筆圧プロファイルで幅変化描画
```
