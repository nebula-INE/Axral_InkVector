# VektorStudio MVP

**次世代ベクタークリエイティブスタジオ — Phase 1 MVP**

## セットアップ

```bash
pip install -r requirements.txt
python main.py
```

## ツール一覧

| キー | ツール | 操作 |
|------|--------|------|
| `P`  | ペン   | クリックでノード追加。ドラッグでベジェハンドル調整。ダブルクリックでパス確定 |
| `A`  | Reshape | パスを選択→ノードをドラッグ。コントロールポイントでカーブ形状を変更 |
| `V`  | 選択   | パス全体をドラッグで移動 |
| `H`  | 手のひら | キャンバスをパン（Alt+ドラッグでも可） |
| `E`  | 消しゴム | パスをクリックで削除 |

## ショートカット

| キー | 操作 |
|------|------|
| `Ctrl+Z` / `Ctrl+Y` | Undo / Redo |
| `Ctrl+S` | 保存 |
| `Ctrl+O` | SVGを開く |
| `Ctrl+0` | キャンバスにフィット |
| `Delete` | 選択ノード/パスを削除 |
| `Escape` | ペン確定 / 選択解除 |
| スクロール | ズーム |
| Alt+ドラッグ | パン |
| ダブルクリック | ペン確定 / パス開閉 |
